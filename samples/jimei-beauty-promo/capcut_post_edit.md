# 剪映(CapCut)後製 SOP

Method A(Pixelle-Video / RunningHub)出來的 mp4 是「AI 生成的原始版」,在剪映做二次調整能顯著拉高質感,也讓每週的成品有變化,不會被觀眾一眼認出「又是同一支 AI 影片」。

**適用**:每次跑完 Method A 都套一次(約 15–20 分鐘/支)
**目標**:輸出可上 FB / IG Reels 的成品 mp4
**工具**:剪映桌面版(Mac / Windows)或手機版,免費即可

## 前置檢查

執行前確認手邊有:

- [ ] Method A 輸出的 mp4:`output/<task_id>/final.mp4`
- [ ] SRT 字幕:`samples/jimei-beauty-promo/subtitles/reels_30s.srt`
- [ ] 品牌色參考:米白 `#F5EFE6` / 暖棕 `#A89377` / 深墨 `#2B2A28`
- [ ] BGM(選一):剪映內建「Ambient / 溫柔鋼琴」或自備 royalty-free 音軌

## 8 步驟

### 1. 建立專案
- 剪映 → 新建 → 選 **1080×1920 直式**(9:16)
- 專案名依 rotation_plan:`jimei_reels_w1_a_20260706`

### 2. 匯入原始 mp4
- 拉入 `final.mp4` 到主視訊軌
- 確認總長 = 30 秒(如超過,末尾修齊)

### 3. 處理字幕(必做)
Pixelle-Video 燒進去的字幕未必符合品牌調性,兩種處理擇一:

**方案 3-a. 覆蓋:直接蓋上新字幕**
- 上方新增文字軌,匯入 `reels_30s.srt`
- 字型:**思源宋體 / Noto Serif TC**
- 大小:60–72 pt
- 顏色:`#2B2A28`(深墨)
- 描邊:淡白 1 pt(避開背景過亮時字看不清)
- 位置:下 25% 安全區(避 IG Reels UI)

**方案 3-b. 抽掉原字幕再重上(要更乾淨)**
- 用「智慧抠圖 → 局部模糊」蓋住原字幕區域
- 或整段重跑 Pixelle-Video 時,把 template 換成不燒字幕的版本(需要工程改)
- 再依 3-a 加新字幕

### 4. 換 / 疊 BGM
- 原檔的 BGM 音量降到 **-∞ dB**(靜音)或直接刪
- 加新 BGM 到獨立音軌,音量 **-18 dB**
- 建議標籤:`ambient piano`、`cinematic minimal`、`spa relaxing`
- 開頭 fade-in 1.0 秒、結尾 fade-out 2.0 秒

### 5. 加開頭品牌小水印(可選)
- 0:00–0:04 左上角疊上「己美 self」文字水印
- 透明度 40%、字型思源宋體 24 pt、白色
- 讓開頭 3 秒就有品牌意識

### 6. 強化結尾 CTA(必做)
Pixelle-Video 燒進去的 CTA 通常太陽春,重做一次:

- 0:26–0:30 蓋上一層品牌卡片,含以下三行:
  1. **己美 self**(思源宋體 96 pt，fade in 0.3 秒)
  2. **己美self.com.tw**(思源黑體 48 pt，delay 0.3 秒後淺入)
  3. **立即註冊會員**(圓角矩形按鈕造型，深墨底 + 米白字，delay 0.6 秒後彈入)

底色可用半透明米白 `rgba(245,239,230,0.85)`,讓底下畫面若隱若現。

### 7. 色調微調(可選)
- 「調節」→ 亮度 +3、飽和度 -8、色溫 +5(讓米白更溫潤)
- 或套「LUT → 電影感 / 靜謐」濾鏡，強度 25–35%
- **不要**加特效濾鏡(閃光、模糊、故障),會破壞品牌氣質

### 8. 匯出設定
- 解析度:**1080×1920**
- 幀率:**30 fps**
- 位元率:**8–15 Mbps**(**別選 4K**,IG Reels 上傳會壓縮兩次)
- 格式:**MP4 (H.264)**
- 音量正常化到 **-14 LUFS**、峰值 **≤ -3 dBFS**
- 檔名:`jimei_reels_w1_a_20260706.mp4`

## 存成剪映模板(下次省事)

第一次做完 W1 A 版 → 專案另存為模板「己美 A 版模板」:

- 下次 W2 A 版:新 mp4 拉進模板,字幕自動對齊,只改結尾字卡文字
- 每週節省 10 分鐘

同法可為 Method B 存「己美 B 版模板」。

## 常見狀況修正

| 狀況 | 修正 |
|------|------|
| 原字幕看不清 | 先在字幕區加半透明白色底(3-a 補救) |
| BGM 蓋過旁白 | BGM 再降 3 dB;或用剪映「智能降噪 → 突出人聲」 |
| 30 秒切到一半怪怪的 | Method A 的實際輸出可能 28–32 秒,調整結尾 CTA 起始時間對齊 |
| 匯出後畫質糊 | 位元率至少 10 Mbps;不要選「小體積」預設 |
| 上 IG Reels 被裁 | 檢查安全區:下 220 px 內不放重要資訊(避開愛心/留言按鈕) |
| 完播率低 | 縮短開頭 fade-in(0.5 秒 → 0.2 秒),開頭 1 秒內要出字幕鉤住 |
